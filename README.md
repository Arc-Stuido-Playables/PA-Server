# PA-Server — сервер плееблов Arc Studio

Сервер для показа плееблов клиентам: заливаете `.html` билд → получаете ссылку →
клиент открывает плеебл в рамке телефона с переключением пропорций экрана.
Функционально повторяет референсный сервер 1-в-1, оформлен в стиле
[arc-studio.tech](https://arc-studio.tech/).

## Гайд по заливке плееблов (для команды)

1. Откройте `https://<сервер>/list`.
2. Внизу страницы нажмите **«Выбрать файл»** (или перетащите файл в рамку).
3. Выберите нужный файл в формате `.html`.
4. Нажмите **«Загрузить»**.
5. Файл появится в списке (он будет подсвечен) — кликните по нему.
6. Скопируйте ссылку из адресной строки (или кнопкой ⧉ в списке) и передайте на апрув.

Удалить плеебл — кнопка 🗑 в строке списка, затем пароль удаления (спросите у лида).

**При внесении правок** оставляем тот же нейминг и заливаем билд заново — он обновится на
сервере по той же ссылке (важно, чтобы имя **точно** совпадало с предыдущим билдом; при
выборе файла форма подскажет «обновит существующий»). Используйте нейминг из таска, например
`04_G5_31пак_EH1234i001v001.html`.

## Что умеет

| Маршрут | Что делает |
|---------|------------|
| `/list` | список всех файлов (поиск, размер, дата, копирование ссылки, удаление по паролю) + форма загрузки |
| `POST /upload` | загрузка только `.html`/`.htm`; файл с тем же именем перезаписывается атомарно |
| `/files/<имя>.html` | viewer: рамка телефона, 9:16 / 16:9 / 3:4 / 4:3, перезапуск, fullscreen, светлый/тёмный фон, бургер-меню на телефоне |

Отличия от референса: принимаются только `.html`/`.htm`, `/` ведёт на `/list`, есть поиск и кнопка копирования ссылки,
кириллица в именах не превращается в `���` (даже если файл залит из Windows-утилиты в
cp1251), оборванная загрузка не портит уже опубликованный файл, опционально — пароль на
список и загрузку.

## Локальный запуск

Нужен Node.js 20+.

```bash
npm install
npm start
```

Откройте http://localhost:8080/list. Файлы складываются в `./data/files`.

Тесты:

```bash
npm test
```

## Деплой

Самый дешёвый вариант — младший облачный сервер Timeweb, без домена, одна команда:

```bash
curl -fsSL https://raw.githubusercontent.com/Arc-Stuido-Playables/PA-Server/main/deploy/install.sh | bash
```

Сервер откроется по `http://<IP сервера>/list`. Подробно (выбор тарифа, пароль, бэкапы,
обновление) — [docs/DEPLOY-TIMEWEB.md](docs/DEPLOY-TIMEWEB.md).

## Настройки

| Переменная | По умолчанию | |
|------------|--------------|--|
| `PORT` | `8080` | порт |
| `DATA_DIR` | `./data` | папка с файлами |
| `MAX_UPLOAD_MB` | `100` | лимит размера файла |
| `ADMIN_USER` / `ADMIN_PASSWORD` | — | пароль на `/list` и загрузку |
| `DELETE_PASSWORD` | — | пароль для удаления плееблов из списка; без него удаление выключено |

## Разработка

Проект ведётся по [Spec Kit](https://github.com/github/spec-kit): конституция —
`.specify/memory/constitution.md`, спецификация, план и задачи — `specs/001-playable-hosting/`.
Структура кода:

```text
server.js        точка входа (env → запуск)
src/app.js       маршруты
src/storage.js   хранение файлов, безопасные имена, атомарная запись
src/views.js     HTML списка и viewer'а
src/auth.js      опциональный Basic auth
public/          CSS/JS/иконки (/assets/*)
tests/           интеграционные тесты (node:test)
```
