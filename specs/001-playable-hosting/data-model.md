# Data Model

## PlayableFile

Хранится как обычный файл `DATA_DIR/files/<name>`; отдельной БД нет.

| Поле | Источник | Правила |
|------|----------|---------|
| `name` | имя файла из формы загрузки | UTF-8; только базовое имя (всё после последнего `/` или `\`); не пустое, не `.`/`..`; без символов `\0`–`\x1f`; ≤ 255 байт |
| `size` | `fs.stat` | байты |
| `mtime` | `fs.stat` | время последней (пере)загрузки |
| `isHtml` | расширение | `.html` / `.htm` без учёта регистра |

Ссылка: `/files/` + `encodeURIComponent(name)`.

## Жизненный цикл загрузки

```text
received → streaming (DATA_DIR/tmp/<rand>) ─ ok ─→ published (rename → files/<name>)
                                          └ error/abort/limit → discarded (tmp удалён)
```

Опубликованный файл меняется только операцией `rename`, поэтому читатели всегда видят
целую версию — старую или новую.
