# Quickstart / Validation

## Запуск

```bash
npm install
npm test
npm start          # http://localhost:8080/list
```

## Ручная проверка

1. Открыть `http://localhost:8080/list`, выбрать `.html` плеебл, «Загрузить» →
   возврат на список, файл подсвечен.
2. Кликнуть по файлу → плеебл в рамке телефона, в заголовке вкладки имя файла.
3. Переключить 16:9 / 3:4 / 4:3 / 9:16, «перезапустить», fullscreen, тумблер фона.
4. Сузить окно до 375px → контролы в бургер-меню.
5. Перезалить файл с тем же именем, но другим содержимым → по старой ссылке новая версия.
6. Загрузить `.zip` → по ссылке скачивается архив.

Контракт маршрутов — [contracts/http.md](./contracts/http.md).
