# Feature Specification: Пароль на список, кнопка звука, без лимита загрузки

**Feature Branch**: `003-access-mute-unlimited`

**Created**: 2026-10-17

**Status**: Implemented

**Input**: User description: "Убери лимит на загрузку и добавь кнопку выключения звука. Страница
/list — доступ только по паролю, плееблы по прямой ссылке доступны всем."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Список только для команды (Priority: P1)

Открывая `/list`, человек без пароля видит страницу входа с одним полем «Пароль». После
верного пароля браузер запоминается на 30 дней. Ссылки `/files/<имя>` открываются всем без пароля.

**Independent Test**: открыть `/list` в чистом браузере → форма входа; ввести пароль → список;
открыть ссылку на плеебл в другом браузере → плеебл без пароля.

**Acceptance Scenarios**:

1. **Given** нет входа, **When** открыт `/list`, **Then** форма входа, файлов не видно.
2. **Given** неверный пароль, **When** «Войти», **Then** «Неверный пароль».
3. **Given** верный пароль, **When** «Войти», **Then** список; повторный заход в течение 30 дней —
   без пароля; «Выйти» сбрасывает вход.
4. **Given** нет входа, **When** загрузка или удаление запросом, **Then** `401`, ничего не меняется.
5. **Given** 5 неверных паролей за 15 минут с одного адреса, **Then** вход блокируется на 15 минут.

### User Story 2 - Выключить звук плеебла (Priority: P1)

В плеере рядом с «перезапустить» есть кнопка звука. Нажатие глушит плеебл (WebAudio и
`<audio>/<video>`), повторное — включает. Выбор запоминается в браузере и сохраняется после
«перезапустить».

### User Story 3 - Без лимита размера (Priority: P2)

Билд любого размера загружается; форма пишет «без ограничения размера». Лимит можно вернуть
переменной `MAX_UPLOAD_MB`.

### Edge Cases

- Пароль не задан на сервере → список открыт, как раньше.
- Подделанная/просроченная cookie → форма входа.
- Плеебл без `<head>`/`<html>` → скрипт звука вставляется после `<!doctype>`, режим документа не меняется.
- Смена пароля на сервере разлогинивает всех.

## Requirements *(mandatory)*

- **FR-001**: `/list`, загрузка и удаление MUST требовать вход по паролю, если он задан
  (`ACCESS_PASSWORD`, по умолчанию = `DELETE_PASSWORD`); `/files/*`, `/assets/*` — открыты.
- **FR-002**: Вход MUST хранить подписанную cookie (HttpOnly, SameSite=Lax, 30 дней) без хранения
  состояния на сервере; пароль MUST NOT попадать в репозиторий.
- **FR-003**: Неверные пароли MUST ограничиваться: 5 за 15 минут на адрес.
- **FR-004**: Плеер MUST иметь кнопку звука, глушащую WebAudio и медиа-элементы плеебла, с
  запоминанием выбора и сохранением после перезапуска.
- **FR-005**: Размер загрузки MUST быть без ограничения по умолчанию; `MAX_UPLOAD_MB` включает лимит.

## Success Criteria *(mandatory)*

- **SC-001**: Без пароля список и загрузка недоступны (100% запросов → вход/401), плееблы доступны.
- **SC-002**: Кнопка звука глушит плеебл за одно нажатие.
- **SC-003**: Билд > 100 МБ загружается.

## Assumptions

- Пароль общий для команды; пользователей и ролей нет.
- Сервер работает по HTTP (без домена), поэтому cookie без флага `Secure`.
