# Feature Specification: Кнопка скачивания плеебла

**Feature Branch**: `004-download-button` · **Created**: 2026-10-17 · **Status**: Implemented

**Input**: "Добавь у каждого плеебла кнопку скачивания — чтобы скачать файл плеебла с сервера"

## User Scenarios & Testing

### User Story 1 - Скачать исходный файл (Priority: P1)

В списке у каждой строки есть кнопка «Скачать». Нажатие сохраняет исходный `.html` плеебла
(без обёртки плеера) под тем же именем, включая кириллицу.

**Acceptance Scenarios**:

1. **Given** файл в списке, **When** нажато «Скачать», **Then** браузер сохраняет файл байт-в-байт
   с исходным именем.
2. **Given** список закрыт паролем и нет входа, **When** запрошено скачивание, **Then** `401`.
3. **Given** файла нет или имя некорректно, **Then** `404`.

## Requirements

- **FR-001**: Каждая строка списка MUST иметь ссылку на `GET /download/<имя>`.
- **FR-002**: `/download/<имя>` MUST отдавать исходный файл с `Content-Disposition: attachment`,
  `filename*=UTF-8''…` и ASCII-запасным `filename`.
- **FR-003**: `/download/*` MUST требовать тот же вход, что и `/list` (фича 003).

## Success Criteria

- **SC-001**: Скачанный файл совпадает с загруженным байт-в-байт (покрыто тестом).
