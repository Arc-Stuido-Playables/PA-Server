# Feature Specification: Конфиг плеебла — параметры в предпросмотре

**Feature Branch**: `005-playable-config` · **Created**: 2026-11-16 · **Status**: Implemented

**Input**: "В каждом плеебле конфиг, который сервер подхватывает на странице предпросмотра; там
можно менять параметры (пока числовые). Сервер их не придумывает, только читает. Сохранить —
плеебл сразу сохраняется с новым значением. Отдельно проверить, можно ли прикрутить сборку
билдов под сетки и автотесты."

## User Stories

1. **Увидеть параметры (P1)** — в предпросмотре плеебла с блоком `pa-config` у команды есть
   панель «Параметры» с числовыми параметрами, которые объявил сам плеебл.
2. **Попробовать (P1)** — изменение значения перезапускает плеебл в рамке с новым значением,
   ничего не сохраняя.
3. **Сохранить (P1)** — «Сохранить» записывает значения в файл плеебла на сервере; ссылка та же.

## Requirements

- **FR-001**: Сервер MUST читать параметры только из блока
  `<script type="application/json" id="pa-config">` плеебла (формат — docs/PLAYABLE-CONFIG.md)
  и MUST NOT добавлять свои.
- **FR-002**: Показываются числовые параметры: число или объект с числовым `value`
  (+ необязательные `min`, `max`, `step`, `label`). Прочие ключи сохраняются как есть.
- **FR-003**: Сохранение MUST менять только блок конфига, атомарно; значение вне `min…max`,
  не число или неизвестный ключ → отказ без изменений.
- **FR-004**: Панель и сохранение — только для вошедших (как `/list`); клиенты видят плеебл без панели.
- **FR-005**: Плеебл без блока или с битым JSON открывается как раньше, без панели.
